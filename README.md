# Portfólio Escolar — versão final

Site estático em HTML, CSS e JavaScript com:
- Apresentação do portfólio;
- Trajetória escolar narrada da Educação Infantil ao Ensino Médio;
- 17 redações revisadas;
- Pesquisa por palavras e temas;
- Cards interativos, leitura individual e opção de copiar o texto;
- Layout responsivo para computador e celular.

## Abrir
Extraia o ZIP, abra a pasta `portfolio_escolar` no VS Code e abra `index.html` no navegador. Também pode usar a extensão Live Server.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie os arquivos e pastas do projeto para a raiz do repositório.
3. Acesse Settings → Pages.
4. Em Build and deployment, selecione Deploy from a branch.
5. Escolha `main` e `/ (root)` e salve.

A trajetória escolar foi redigida em primeira pessoa como uma narrativa geral, conforme solicitado, sem campos ou espaços de preenchimento.
